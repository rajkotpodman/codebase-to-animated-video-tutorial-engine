6-Stage Autonomous Engine Pipeline

STAGE 01

Repomix Ingestion

Clones repository and packs source files while stripping unnecessary artifacts.

STAGE 02

AST Dependency Graph

Extracts imports, classes, and controller routing topology into a clean JSON graph.

STAGE 03

Gemini 1.5 Synthesis

Writes a 4-scene technical script directly in any requested target language.

STAGE 04

Neural Voice & SRT

Synthesizes Edge-TTS voiceovers across 21+ languages and creates subtitle cues.

STAGE 05

Manim Vector Graphics

Renders coordinate-based animations scaled dynamically to narration length.

STAGE 06

FFmpeg Composition

Applies tpad hold filter to prevent black screens and burns subtitles into 1080p MP4.
