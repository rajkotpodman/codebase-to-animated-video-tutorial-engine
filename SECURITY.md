# 🔒 Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within the Codebase-to-Animated Video Tutorial Engine, please report it responsibly:

* **Email**: Please send an email directly to security / maintainers or open a confidential Security Advisory on GitHub.
* **Do NOT create public issues** for zero-day vulnerabilities or credential leaks.

### When reporting, please include:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce the issue (including sample payloads or target repositories).
3. Potential impact on server host, user databases, or API keys.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
